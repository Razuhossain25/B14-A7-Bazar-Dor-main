## 📖 প্রজেক্ট পরিচিতি (Project Overview)

**বাজার দর (BazarDor)** হলো আধুনিক ওয়েব প্রযুক্তিভিত্তিক একটি নিত্যপ্রয়োজনীয় পণ্যের বাজারদর পর্যবেক্ষণ ও তুলনা প্ল্যাটফর্ম। এটি অফিশিয়াল ক্লাউডফ্লেয়ার ওয়ার্কার্স এপিআই (Cloudflare Workers API) থেকে রিয়েল-টাইমে পণ্য ও বিভিন্ন বিভাগের বাজারের তথ্য সংগ্রহ করে সাধারণ ক্রেতাদের সঠিক সিদ্ধান্ত নিতে সহায়তা করে।

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (5 Key Features — Challenge C2)

1. **🔴 লাইভ মারকুই প্রাইস টিকার (Live Infinite Price Ticker):**
   * ওয়েবসাইটের ন্যাভবারের নিচে অবিরাম স্ক্রলিং স্ট্রিপ যেখানে প্রতিটি পণ্যের আইকন, নাম, বাংলা অঙ্কে মূল্য এবং মূল্য পরিবর্তনের হার (▲ বৃদ্ধি / ▼ হ্রাস / — অপরিবর্তিত) রঙিন ব্যাজ সহ প্রদর্শিত হয়।

2. **⚖️ বাজার বিশ্লেষণ ও বিভাগীয় তুলনা (Market & Division Analytics):**
   * সুরক্ষিত প্রোডাক্ট ডিটেইলস পেজে প্রতিটি পণ্যের জন্য সর্বোচ্চ দাম, সর্বনিম্ন দাম এবং গড় দাম প্রদর্শিত হয়। সাথে সাথে ঢাকা, চট্টগ্রাম, রাজশাহীসহ বিভিন্ন বিভাগীয় প্রধান বাজারের রেঞ্জ (`min` ও `max`) তুলনা করার টেবিল রয়েছে।

3. **📊 আজ দাম বেড়েছে ও কমেছে (Top Risers & Fallers Filter):**
   * আজকের বাজারে সবচেয়ে বেশি দাম বৃদ্ধি পাওয়া শীর্ষ ৬টি পণ্য এবং সবচেয়ে বেশি দাম কমা শীর্ষ ৬টি পণ্য স্বয়ংক্রিয়ভাবে আলাদা সেকশনে সাজানো থাকে।

4. **🔍 ক্যাটাগরি ব্রাউজিং ও সংখ্যাভিত্তিক সর্টিং (Challenge C1):**
   * ৮টি ভিন্ন ক্যাটাগরি (চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ, মসলা) ভিত্তিক ফিল্টারিং। সাথে রয়েছে বাংলা সংখ্যা সমর্থনকারী নিউমেরিক সর্ট ড্রপডাউন (ডিফল্ট, কম থেকে বেশি, বেশি থেকে কম)।

5. **🔐 নিরাপদ অথেন্টিকেশন ও প্রোফাইল আপডেট (BetterAuth & Challenge C3):**
   * BetterAuth চালিত ইমেইল-পাসওয়ার্ড এবং সোশ্যাল লগইন (Google, GitHub)। প্রোটেক্টেড রুটে স্বয়ংক্রিয় টোস্ট রিডাইরেক্ট এবং ব্যবহারকারীর নাম আপডেটের জন্য ডেডিকেটেড রুট (`/profile/update`)।

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ (Technologies Used)

| প্রযুক্তি | ব্যবহারের উদ্দেশ্য |
|---|---|
| **Next.js 15 (App Router)** | আধুনিক ফুলস্ট্যাক রিঅ্যাক্ট ফ্রেমওয়ার্ক ও ডাইনামিক রাউটিং |
| **Tailwind CSS v4 & DaisyUI** | আধুনিক রেসপনসিভ ইউজার ইন্টারফেস এবং গ্রিড লেআউট |
| **BetterAuth (In-Memory Adapter)** | আধুনিক অথেন্টিকেশন, সেশন ম্যানেজমেন্ট ও ইউজার অ্যাকাউন্ট |
| **Cloudflare Workers REST API** | পণ্য ও ক্যাটাগরি ডেটা সংগ্রহের জন্য লাইভ এপিআই |
| **react-hot-toast** | ইন্টারেক্টিভ সাকসেস, এরর ও ভ্যালিডেশন নোটিফিকেশন |
| **Hind Siliguri Font** | পরিষ্কার এবং দৃষ্টিনন্দন বাংলা টাইপোগ্রাফি |

## ⚙️ প্রজেক্ট রান করার নিয়ম (Setup & Installation)

### ১. ডিপেন্ডেন্সি ইন্সটল করুন
```bash
npm install
```

### ২. এনভায়রনমেন্ট ভ্যারিয়েবল কনফিগারেশন
`.env.example` ফাইল কপি করে `.env.local` তৈরি করুন:
```bash
cp .env.example .env.local
```
এবং প্রয়োজনীয় কি-গুলো পূরণ করুন:
```env
BETTER_AUTH_SECRET=your_32_character_better_auth_secret_here
BETTER_AUTH_URL=http://localhost:3000
NEXT_PUBLIC_APP_URL=http://localhost:3000

# ঐচ্ছিক সোশ্যাল লগইন (যদি ব্যবহার করতে চান):
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করুন।

### ৪. প্রোডাকশন বিল্ড পরীক্ষা
```bash
npm run build
npm run start
```
